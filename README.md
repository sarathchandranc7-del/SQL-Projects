# SQL Projects

This repository contains my **SQL assignments and practical projects** completed as part of my Data Analytics learning journey. Each assignment focuses on applying SQL concepts to create, manage, manipulate, and analyze data using real-world database scenarios.

This repository will be continuously updated with new SQL assignments and projects as I progress, with each submission demonstrating the SQL concepts and problem-solving skills I have learned.

## 1. My SQL Project — DDL Commands and Constraints

This assignment focuses on **SQL DDL commands and database constraints**, covering the creation and structure of databases and tables. It demonstrates the use of commands such as `CREATE`, `ALTER`, and `DROP`, along with constraints including **PRIMARY KEY, FOREIGN KEY, NOT NULL, UNIQUE, and AUTO_INCREMENT** to maintain data integrity and properly organize relational data.
